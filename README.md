# 🇧🇷 Português

## 📌 Sobre o projeto

O **Vasconcellos e Mendes** é o site institucional de um escritório de advocacia fictício, de alto padrão, construído para transmitir autoridade e exclusividade sem recair no visual corporativo genérico — sem grids infinitos, sem excesso de ícones e sem a previsibilidade comum em sites de escritórios jurídicos.

Este repositório contém o **código-fonte completo do frontend**, publicado como projeto de portfólio.

## 🎯 Proposta da página

O objetivo é conduzir o visitante por uma experiência editorial e refinada, reforçando seriedade e confiança em cada seção:

* Causar uma primeira impressão elegante e forte na hero
* Apresentar o escritório de forma humana, sem recorrer a cards
* Mostrar as áreas de atuação em uma navegação mais editorial, não em grid padrão
* Reforçar diferenciais com uma composição moderna e não repetitiva
* Apresentar a equipe de forma minimalista
* Explicar o processo de atendimento como uma timeline elegante
* Exibir artigos/conteúdos com visual clean
* Fechar com um CTA final discreto e sofisticado

## ✨ Estrutura da página

### 🎥 Hero

* Composição assimétrica, com headline forte, texto de apoio refinado, CTA discreto e imagem sofisticada
* Animações leves na entrada dos elementos

### 🤝 Sobre o escritório

* Layout mais humano, sem cards, apresentando a história e os valores do escritório

### 📚 Áreas de atuação

* Navegação lateral com accordion sofisticado, no lugar do grid tradicional
* Áreas: Direito empresarial, Trabalhista, Tributário, Previdenciário e Cível

### 💎 Diferenciais

* Composição moderna, evitando repetição visual entre os itens

### 👥 Equipe

* Apresentação minimalista e elegante dos advogados do escritório

### 🧭 Processo de atendimento

* Timeline horizontal elegante, explicando as etapas do atendimento de forma visual

### 📰 Artigos e conteúdos

* Seção com visual clean e editorial, destacando conteúdos e publicações do escritório

### 📣 CTA final e footer

* Chamada final sofisticada e discreta
* Footer premium e minimalista

## 🎨 Identidade visual

* Base predominantemente em preto, branco e cinza
* Detalhes em dourado/champagne, usados com parcimônia para reforçar exclusividade
* Tipografia refinada e muito espaço em branco
* Cada seção com estrutura própria, reforçando a sensação de site feito sob medida

## 🎬 Animações e experiência

* Animações suaves construídas com **Framer Motion**
* Transições discretas entre seções, sem comprometer a seriedade do site
* Responsividade tratada com cuidado, mantendo a mesma sofisticação em qualquer tamanho de tela

# 🇺🇸 English

## 📌 About

**Vasconcellos e Mendes** is the institutional website for a fictional, high-end law firm, built to convey authority and exclusivity without falling into a generic corporate look — no infinite grids, no icon overload and no predictability of common law firm websites.

This repository contains the **complete frontend source code**, published as a portfolio project.

## 🎯 Page Concept

The goal is to guide the visitor through an editorial, refined experience, reinforcing seriousness and trust in every section:

* Create a strong, elegant first impression in the hero
* Present the firm in a human way, without relying on cards
* Show the practice areas through a more editorial navigation, not a standard grid
* Reinforce differentiators with a modern, non-repetitive composition
* Present the team in a minimalist way
* Explain the client process as an elegant timeline
* Display articles/content with a clean visual
* Close with a discreet, sophisticated final CTA

## ✨ Page Structure

### 🎥 Hero

* Asymmetrical composition, with a strong headline, refined supporting text, discreet CTA and sophisticated image
* Light animations on element entrance

### 🤝 About the Firm

* More human layout, with no cards, presenting the firm's history and values

### 📚 Practice Areas

* Side navigation with a sophisticated accordion, instead of the traditional grid
* Areas: Corporate law, Labor law, Tax law, Social security law and Civil law

### 💎 Differentiators

* Modern composition, avoiding visual repetition between items

### 👥 Team

* Minimalist, elegant presentation of the firm's attorneys

### 🧭 Client Process

* Elegant horizontal timeline, visually explaining the stages of the client process

### 📰 Articles and Content

* Clean, editorial section highlighting the firm's content and publications

### 📣 Final CTA and Footer

* Sophisticated, discreet final call-to-action
* Premium, minimalist footer

## 🎨 Visual Identity

* Predominantly black, white and gray base
* Gold/champagne details, used sparingly to reinforce exclusivity
* Refined typography and plenty of white space
* Each section with its own structure, reinforcing the feel of a custom-built site

## 🎬 Animations and Experience

* Smooth animations built with **Framer Motion**
* Discreet transitions between sections, without compromising the site's seriousness
* Responsiveness handled carefully, keeping the same sophistication on any screen size

## 🧩 Tech Stack

| Technology | Purpose |
|---|---|
| **Next.js** | Development environment and build tool |
| **React** | Interface development |
| **TypeScript** | Project typing |
| **Tailwind CSS** | Styling and responsive layouts |
| **Framer Motion** | Animations and smooth transitions |

## 🚀 Getting Started

```bash
git clone https://github.com/BeThomazzi/vasconcellos-mendes.git
cd vasconcellos-mendes
npm install
npm run dev
```

The application will usually be available at `http://localhost:3000`.
